# Chapters

This folder is the primary structure for the repository. Each chapter from Python Crash Course gets its own folder, and inside that folder we keep the related notes, exercises, and project work together.

## Suggested layout
```text
chapters/
├── chapter_01/
│   ├── README.md
│   ├── notes/
│   ├── exercises/
│   └── projects/
├── chapter_02/
│   ├── README.md
│   ├── notes/
│   ├── exercises/
│   └── projects/
└── ...
```

This keeps the book structure clear and makes it easier to find work tied to a specific chapter.
